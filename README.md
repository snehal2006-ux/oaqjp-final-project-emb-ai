# Final Project

## Project Name
Final Project

## Description
Simple Interest Calculator

This project calculates simple interest using the principal amount, rate of interest, and time period.

## Formula
Simple Interest = (Principal × Rate × Time) / 100

## Features
- Takes principal amount as input.
- Takes rate of interest as input.
- Takes time as input.
- Calculates simple interest.
